# Factory V1.5

Date: 2026-11-27

## The need

V1.5 is the lean factory. Before the factory gains a lane to change itself, its code and tests are cut to what defends its invariants. The invariants standard and the test cleanup come in later changes of this same version.

## What V1.5 changes

The definition is in [`factory/README.md`](../README.md).

- **Dead code and needless exports are gone from the CLI.** `gitCommand` and `PRICES_EFFECTIVE`, which nothing used, are deleted; the prices' effective date stays as a comment above `PRICES`. 77 symbols that no other file uses lose their `export`, and the re-exports of `REVIEWER_ROLES` from `seal.ts` and `COPIED_WORDS` from `commands/lifecycle.ts` are dropped. Tests and the `factory watch` page, which loads `watch/state.ts`, count as users. No behavior changes.

- **The factory comes first.** `CLAUDE.md` states the project's first goal, showing how an agentic coding system is built while the whole project is managed with AI, and judges every proposal first by the decision it shows in the factory (its isolation, its gates, its routing), then in the product. The root `README.md` says the factory is half of the project.
