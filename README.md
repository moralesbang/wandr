# Wandr

A web map journal for walks. After a walk, you place what caught your eye on a map, each find with a note, and optionally draw the route you want to repeat. When you want to, you share only the finds and the stretch you choose, through a link that opens without an account and that you can revoke at any time.

A portfolio project, built to practice senior software engineering with AI-assisted development.
